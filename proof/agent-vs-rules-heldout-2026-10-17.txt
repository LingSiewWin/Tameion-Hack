## What code would have offered (checked after the labels were frozen and both runs had finished)
The brief's format example offers `pay` on an `invoice`; code never does. My cases inherited that. From the code:
- an invoice is offered [ask, refuse], or [refuse] when frozen or a look-alike (decide.rs:244-250, built at decide.rs:791);
- a bill is offered by the verifier's verdict: Block [refuse]; Review [ask, refuse]; Allow with early terms in Autopilot
  [pay_early, wait]; Allow [pay, ask] + wait if before the due date + refuse (decide.rs:213-238);
- confidence below the Autopilot floor 0.75 makes the verdict Review (crates/ledger/src/verify.rs:1053-1056; floor 7,500 bp at
  crates/ledger/src/action.rs:181);
- a bill's amount always equals its usual (crates/operator/src/lib.rs:2063-2066), so a changed amount reaches the decider only as
  an invoice;
- no production code builds a purchase case yet (kind purchase is set only in tests).
