Lazy deploy at a reserved address (PLAN 5.32, docs/59 §3.17–3.18: the ERC-6492 idea done
with the EIP-7997 factory) — Arc testnet, 2026-10-14

What: Start reserves the account instead of deploying it. The owner's address is
CREATE2(factory, principal_salt(qx, qy), PasskeyPrincipal initcode) and the policy's is
CREATE2(factory, policy_salt(owner, bill wallet, kind), BudgetPolicy initcode); the agent
key is minted; nothing is sent. The tenant file carries deployed:false and the passkey
key. Money can be sent to — or allowed for — the policy's address before it exists. The
first pass (level1::run) or the first passkey challenge (level1_challenge for that owner)
materialises both contracts at the reserved addresses, then gases the agent. Each step
is saved as it lands, so a failure on the next step keeps the hashes and the retry is
idempotent (the factory returns the existing address with no transaction when code is
already there).

Code: level1::{reserve, ensure_deployed, policy_salt, principal_initcode, policy_initcode};
deploy = reserve + ensure_deployed; route POST /api/level1/deploy {lazy:true}; inbox
`deployed`; status for a reserved tenant reads what the address can already reach (hold:
USDC sent to it; pull: min(wallet balance, allowance)); the page's Start reserves and
starts the first pass by itself the moment that is > 0. Unit tests: policy_salt is per
(owner, wallet, kind); a tenant file without `deployed` loads as deployed.

Chain of custody: Start writes a file, not a transaction. The owner's and the policy's addresses
are a function of the passkey, the bill wallet and the kind, so money can go to them first — a
transfer (run 1) or an allowance (run 2). The first check creates the contracts at exactly those
addresses (the factory would land anywhere else only if the salt or the initcode differed, and
ensure_deployed refuses a mismatch) and the money is already inside or already reachable. The
treasurer did three things: typed two facts, tapped Start, tapped Allow. Deploy cost moved from
onboarding to the first moment it is needed, and a tenant that never funds costs the relayer
nothing.
